# Portafolio web responsivo

Pagina web personal (portafolio) adaptable a computadora, tablet y celular,
desarrollada con HTML5 y CSS3. Usa consultas de medios (media queries) para
las vistas vertical (portrait) y horizontal (landscape).

## Archivos
- `index.html` - estructura de la pagina (HTML5 semantico, con viewport).
- `estilos.css` - hoja de estilos, incluye las media queries para movil.

Asignatura: Desarrollo Web - AVS.02.05.01 Pagina web adaptativa.
